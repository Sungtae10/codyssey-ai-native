# 제출 증빙 체크리스트 (공식 Final Project 기준)

기준 문서는 코디세이 미션 "AI 네이티브 Final Project 자율 주제"의 2장(최종 결과물), 4장(기능 요구 사항), 5장(개발 환경), 6장(제약 사항)입니다. 겹치는 항목을 합쳐 19개로 정리했습니다. 2026-10-15에 대조했고, 이전의 잠정 6개 항목(다른 팀 결과보고서 기준)은 이 표로 바꿨습니다. 10/19(저녁, 23시)에 상태와 남은 일을 고쳤습니다. 한눈에 보는 요약은 [공식 요구사항 ↔ 증빙 매트릭스](official-requirements-matrix.md)에 있습니다.
