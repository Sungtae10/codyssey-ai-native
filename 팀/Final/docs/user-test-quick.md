# 사용자 테스트: 빠른 운영안

공식 요건은 실제 사용자 5명 이상과 피드백 수집·반영입니다. 시간이 부족하므로 복잡한 A/B 비교 대신 아래 최소안을 씁니다.

## 기본: 혼자 써 보는 방식 (10/19, 진행자 없이)

진행자가 없어도 되도록, 과제를 설문 안에 넣었습니다 (`eval/user_test/create_form.gs`의 `updateSurvey`). 설문 링크는 그대로입니다.

1. 화면에 실제 기업 데이터가 있어야 합니다. 10/19부터 사람이 원문 대조한 검증용 시연 데이터(PR #19)가 올라가 있습니다. 김성태가 단톡에 "보내도 돼요"라고 알리면 보냅니다. 시연용 3곳은 테스트에 필요하지 않습니다.
2. 김서원이 취업·이직 준비자를 먼저, 최소 5명(공식 기준), 여유가 있으면 6~10명에게 서비스 링크와 설문 링크를 개인 메시지로 보냅니다.
3. 참가자는 혼자 서비스를 2~3분 써 보고 설문에 답합니다 (약 5분).
4. 응답은 응답 시트에 자동으로 쌓입니다. 참가자 번호는 비워 둬도 됩니다.

설문에 들어간 작은 과제:

| 문항 | 내용 | 결과에 쓰는 법 |
| --- | --- | --- |
| 지금 상황 | 취업 준비 / 이직 준비 / 재직 / 학생 / 기타 | 대상 사용자(취업·이직 준비자) 비율 |
| 과제 1 | 고른 기업과 "근거 확인" 약속 1개 | 화면 데이터와 대조해 맞게 찾았는지 |
| 과제 2 | 근거가 나온 보고서 | 과제 1과 함께 정답 여부 |
| 과제 3 | 서비스에서 찾는 데 걸린 시간 (구간) | 4분 안에 해낸 비율 |
| 과제 4 (선택) | DART에서 직접 찾으면 걸릴 것 같은 시간 | 참가자의 예상치로만 씁니다. 실제로 잰 시간이 아니므로 "몇 분 단축"으로 바꾸지 않습니다 |

## 선택: 진행자와 함께 하는 방식 (화면공유)

시간이 되는 참가자와 할 때만 씁니다. 자세한 절차는 `docs/user-test-protocol.md`에 있습니다.

1. 참가자 번호를 줍니다: P01부터
2. 서비스 링크를 열어 기업 하나를 고르게 합니다.
3. 2~3분 동안 자유롭게 쓰게 합니다.
4. 과제 한 가지를 줍니다: "이 회사가 과거에 밝힌 AI 계획 중 후속 공시에서 근거가 확인되는 사례 하나를 찾아보세요."
5. 사용 후 같은 Google Form을 제출하게 합니다.

## 설문

같은 Google Form을 씁니다 (https://forms.gle/33fFVGSNSQHRriAg9). 문항:
- 참여 동의, 참가자 번호(선택)
- 지금 상황, 작은 과제 1~4 (10/19 추가)
- 판정 이유·근거 이해도 1~5
- 결과 신뢰도 1~5
- 면접 활용 의향 1~5
- 개선 의견
- 가장 도움 된 기능
- 한 줄 총평

## 원칙
- 답을 알려주지 않습니다.
- 사용 중 막히는 지점을 메모합니다 (화면공유 때).
- 개인정보는 받지 않습니다. 참가자 이름과 연락처는 시트, 공유 폴더, 단톡에 적지 않습니다.
- 최소 5명이 끝나면 공식 사용자 수 요건을 채웁니다.
- 테스트가 모두 끝난 뒤 가장 반복된 피드백 1~2개를 실제로 고치고 `docs/feedback-log.md`에 적습니다.
