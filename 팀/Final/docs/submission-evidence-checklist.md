# 제출 증빙 체크리스트 (공식 Final Project 기준)

기준 문서는 코디세이 미션 "AI 네이티브 Final Project 자율 주제"의 2장(최종 결과물), 4장(기능 요구 사항), 5장(개발 환경), 6장(제약 사항)입니다. 겹치는 항목을 합쳐 19개로 정리했습니다. 2026-10-15에 대조했고, 이전의 잠정 6개 항목(다른 팀 결과보고서 기준)은 이 표로 바꿨습니다. 10/19에 상태와 남은 일을 고쳤습니다. 한눈에 보는 요약은 [공식 요구사항 ↔ 증빙 매트릭스](official-requirements-matrix.md)에 있습니다.

상태는 "지금 증빙이 있는가"로만 정합니다. 증빙은 저장소, 배포 주소, 팀이 함께 쓰는 문서(기획 보고서 등)에 있는 것을 셉니다. 문서를 저장소에 올리는 일은 #8에서 따로 셉니다.

- ✅ 충족: 증빙이 지금 있음
- 🟡 일부: 증빙이 일부만 있고, 나머지는 담당이 정해져 있음
- ⬜ 아직: 증빙이 아직 없고, 담당이 정해져 있음
- 🔴 부족: 증빙도 없고 일정도 없음 (지금은 없음)
