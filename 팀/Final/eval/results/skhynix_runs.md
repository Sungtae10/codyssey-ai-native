# SK하이닉스 시범 평가: 사람 정답 vs AI 판정 (10/19, n=3)

사람 정답은 김성태·김서원이 엔진을 돌리기 전에 공동 검토로 고정했습니다 (`eval/gold/skhynix_합의.csv`, 구체적 약속 3건: 공시에서 확인 불가 2, 일부 확인 1). 판정기준 v2는 바꾸지 않았습니다.
AI 판정은 GitHub Actions `Engine run`(OpenDART 자동 수집 → 엔진 1~7단계 → `eval/evaluate.py`)으로 만들었고, 실행마다 결과를 `engine-results/<실행번호>-skhynix-<순번>` 브랜치에 남겼습니다 (로그, judged.json, 결과표, 받은 DART 글).

## 최종 엔진으로 같은 입력을 3번 실행 (재현성 점검)

| 실행 | 엔진 커밋 | 일치 (사람 정답 3건 중) | SOCAMM·LPCAMM 대응 (정답: 확인 불가) | ZUFS 4.0 양산 (정답: 확인 불가) | QLC 61TB 기술력 확보 (정답: 일부 확인) |
| --- | --- | --- | --- | --- | --- |
| 39256926926-0 | 15af1ff | 2 | 확인 불가 | 확인 불가 | 근거 확인 |
| 39256926926-1 | 15af1ff | 3 | 확인 불가 | 확인 불가 | 일부 확인 |
| 39256926926-2 | 15af1ff | 2 | 확인 불가 | 확인 불가 | 근거 확인 |
| 회차별 | | **1회차 2/3, 2회차 3/3, 3회차 2/3** | 3/3 | 3/3 | 1/3 |

- 세 번 모두: 인용 원문 일치 100%, 근거 없는 실행 판정 0건, 사람이 찾은 약속을 AI도 찾은 비율 4/4 (AI 관련 말이 없는 1문장은 판정기준 v2로 뺌).
- 사람 정답과 다른 판정은 1회차와 3회차에 나왔고, 두 번 모두 같은 약속(QLC 61TB) 1건입니다. AI는 세 번 모두 2025 사업보고서의 "[PS1012] AI 데이터센터용 QLC 기반 고용량(61TB) PCIe 5세대 SSD 제품" 문장을 근거로 찾았고, 같은 근거로 두 번은 '근거 확인', 한 번은 '일부 확인'으로 판정했습니다. 사람 정답은 2026 반기보고서의 "321단 QLC" 문장으로 '일부 확인'입니다. 사람 검토 때 보지 못한 문장일 수 있어 **정답 재검토 후보**로 남기지만, AI 결과를 본 뒤 정답을 바꾸면 평가가 공정하지 않아 정답은 그대로 둡니다.
- 같은 약속 3개를 3번 반복한 것이라 독립 표본 9개가 아닙니다. 그래서 합쳐서 정확도(예: 78%)로 해석하지 않고 회차별로만 적습니다 ("시범 평가"). 같은 입력에서도 실행마다 판정이 달라질 수 있다는 점(LLM 출력의 흔들림)을 함께 적습니다.
- 실패 분석 (QLC 61TB): 세 번 모두 같은 근거 문장을 찾아 **검색은 안정적**이었고, 같은 근거를 두고 근거 확인과 일부 확인 사이에서 **판정 경계가 흔들렸습니다**. 후속 개선 후보: 경계 판정 규칙(수량·시점 조건) 추가, 판정 뒤 근거가 약속을 충분히 뒷받침하는지 한 번 더 묻는 2단계 확인, 여러 번 돌려 판정이 갈리면 "판정이 갈림"으로 표시.
