## 1. 여는 법

- **가장 쉬운 방법**: `index.html`을 더블클릭하면 브라우저에서 열려요. 이때는 예시 데이터로 보여요.
- **실제 결과로 보기**: `data/results.json`을 넣고, 폴더를 웹 서버로 열어야 해요.
  ```
  cd app        # 저장소 맨 위 폴더에서
  python3 -m http.server 8000
  ```
  그다음 브라우저에서 `http://localhost:8000`을 열어요.
- **배포**: 폴더 전체를 그대로 올리면 돼요. 빌드 과정이 없는 순수 HTML/CSS/JS라서 Vercel에 그대로 올라가요.

## 2. 화면과 주소

| 화면 | 주소 |
|---|---|
| 1. 회사 검색 (분석 완료 기업, 분석 준비 중 기업) | `#/` |
| 2. 약속 목록 | `#/c/<기업 id>` (예: `#/c/demo-a`) |
| 3. 약속 자세히 보기 | `#/c/<기업 id>/p/<약속 id>` (예: `#/c/demo-a/p/demo-a-p1`) |
| 4. 면접 카드 | `#/c/<기업 id>/card` |
| 5. 내 경험 연결 (이력서) | `#/c/<기업 id>/fit` (서버 함수 `api/resume-fit` 필요, 없으면 "준비 중") |

오른쪽 위 해/달 버튼으로 다크와 라이트를 바꿀 수 있어요. 고른 테마는 다음에 들어와도 기억돼요.

## 3. 파일 구조

```
index.html            화면 틀
css/style.css         디자인 (색, 글꼴, 크기)
js/app.js             화면 4개를 그리는 코드
data/sample-data.js   예시 데이터 (공통 폴더 sample_data.json과 같은 내용, 가상 회사)
data/results.json     ← 화면 데이터 (사람 원문 검토 2곳 + AI 엔진 결과 3곳, 10/19부터)
```

`data/results.json`을 읽어요. 못 읽으면 운영 사이트에서는 안내를 띄우고, 이 컴퓨터에서 열 때나 `?sample=1`일 때만 예시 데이터를 써요 (10/20).

## 4. 결과 파일 형식

화면 안내서 4장의 `sample_data.json` 형식을 그대로 읽어요. 엔진은 같은 형식으로 결과를 만들어요.

```
python run.py export --companies samsung   # 화면 파일은 그대로, 결과는 data/results/ 에만
# 사용자 테스트가 끝나고 SK하이닉스 합의 뒤에만: python run.py export --companies samsung skhynix --copy-to <저장소>/app/data/results.json
```

| 판정 값 | 화면 문구 | 색 |
|---|---|---|
| `evidence_found` | 근거 확인 | 초록 |
| `partial` | 일부 확인 | 주황 |
| `not_verifiable` | 공시에서 확인 불가 | 회색 (빨간색, 경고 표시 쓰지 않음) |
| `company_reported_not_pursued` | 회사가 미추진으로 공시 | 남보라 |
| (방향성 약속, 판정 없음) | 방향성 약속 | 회색 |

## 5. 디자인 바꾸는 법

색은 모두 `css/style.css` 맨 위 **"1. 디자인 값"**에 모여 있어요.

- 다크 색: `[data-theme="dark"]` 안의 값
- 라이트 색: `[data-theme="light"]` 안의 값
- 판정 색: `--confirmed`, `--partial`, `--not_found`, `--not_pursued`
- 글꼴: `--font`
- 모서리 둥글기: `--radius-lg`, `--radius-md`, `--radius-sm`
- 10/12에 더한 부품(예시 안내 띠, 안내 문구, 방향성 묶음, 원문 존재 확인 표시(예전 이름 원문 확인됨))은 맨 아래 "12." 부분에 있어요. 지우면 화면 일부가 깨져요.
- 색을 바꾸면 글자 대비가 작은 글자 4.5:1, 큰 글자 3:1 이상인지 확인해요. 저장소 맨 위 폴더에서 `python tests/ui_check.py`를 돌리면 결과 파일 화면(있을 때)과 예시 데이터 18개 화면을 다크·라이트, 390·320·1280px로 열어 글자 대비, 가로 넘침, 그려지지 않은 화면("찾는 화면이 없어요", "화면을 그리지 못했어요"), 결과 파일 대신 예시 데이터가 조용히 나온 경우, 첫 화면 검색 3상태(분석 완료, 아직 분석 전, 찾지 못함)를 확인해 줘요. `python tests/test_ui_static.py`는 `app.js`가 쓰는 class가 CSS에 다 있는지 봐요.
