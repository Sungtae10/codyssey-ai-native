# 시연용 기업 계획 (10/19 확정)

10/12 기획 보고서 3차 개정에서는 "관문 2를 통과하면 업종이 다른 시연용 기업을 최대 3곳"으로 정했고, 10/19에 마감 최소안(`docs/final-sprint.md`)으로 3곳을 확정했습니다.

## 기업
| 구분 | 기업 | 역할 |
| --- | --- | --- |
| 핵심 | 삼성전자 | 개발용 (판정기준과 엔진을 맞추는 기업, 화면 시연) |
| 핵심 | SK하이닉스 | 평가용 (AI 결과를 보기 전에 고정한 사람 정답과 AI 판정을 비교. 10/19 정답은 김성태·김서원 공동 검토) |
| 시연용 | 카카오, 신한은행, NAVER | 제품 확장성 시연. `engine/config.yaml`의 `candidates` (`kakao`, `shinhanbank`, `naver`) |

- 시연용 기업은 사람 정답과 비교하지 않습니다. 화면에 시연용 안내(`check_note`)를 붙이고, 평가 숫자에는 넣지 않습니다.
- 핵심 2곳과 사용자 5명 테스트를 먼저 끝내고, 시간이 남을 때만 진행합니다 (`docs/final-sprint.md` 우선순위 7번).
- 10/12 후보였던 현대자동차, LG전자는 10/19에 설정에서 뺐습니다 (PR #16).
- 문장 분류 ML 실험은 이번 제출에서 하지 않습니다 (기획 보고서 8.3). 자세한 내용은 `eval/ml/README.md`에 있습니다.

## 화면에 넣는 조건
2024 사업보고서의 지정 섹션에서 판정기준 v2에 맞는 **구체적 AI 약속이 최소 3개** 있어야 합니다. 3개보다 적은 기업은 화면에 넣지 않고 단톡에 알립니다.

확인 명령 (engine 폴더에서):

```bash
python run.py scan --company kakao     # 2024 사업보고서 1개로 미리 보기
python run.py all --company kakao      # PDF 3개가 다 있으면 바로 끝까지
```

## 시연용 기업의 검증 수준
- 실제 DART 정기공시만 사용
- 약속 원문 보존, 근거 원문 보존
- 인용 검사(Citation Verification) 통과
- `engine/run.py check` 통과
- 팀이 약속과 근거를 원문과 대조해 확인 (서원님 확인 표, 드라이브 `1019_서원님_할일_하는법` 4장)

다만 삼성전자·SK하이닉스처럼 두 사람이 모든 약속을 따로 판정하지는 않습니다.
