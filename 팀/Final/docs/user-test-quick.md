# 사용자 테스트 — 빠른 운영안

공식 요건은 실제 사용자 5명 이상과 피드백 수집·반영이다. 시간 부족 시 복잡한 A/B 비교 대신 아래 최소안을 사용한다.

## 1인 진행
1. 참가자 번호 부여: P01~P05
2. 서비스 링크를 열어 기업 하나를 선택하게 한다.
3. 2~3분 동안 자유롭게 사용하게 한다.
4. 다음 한 가지 과제를 준다:
   - "이 회사가 과거에 밝힌 AI 계획 중 후속 공시에서 근거가 확인되는 사례 하나를 찾아보세요."
5. 사용 후 기존 Google Form을 제출하게 한다.

## 설문
기존 Google Form을 그대로 사용:
- 판정 이유·근거 이해도 1~5
- 결과 신뢰도 1~5
- 면접 활용 의향 1~5
- 개선 의견
- 가장 도움 된 기능
- 한 줄 총평

## 진행자 원칙
- 답을 알려주지 않는다.
- 사용 중 막히는 지점을 메모한다.
- 개인정보는 받지 않는다.
- 최소 5명 완료하면 공식 사용자 수 요건을 충족한다.
- 5명 전부 끝난 뒤 가장 반복된 피드백 1~2개를 실제로 수정한다.

## 결과 보고 예시
- 테스터: 5명
- 이해도 평균: 실제 값
- 신뢰도 평균: 실제 값
- 활용 의향 평균: 실제 값
- 주요 피드백: 실제 응답
- 반영: 실제 commit/PR
