# 사용자 테스트 프로토콜

## 목적
AI Promise가 직접 검색보다 기업 AI 약속의 실행 근거를 더 빠르고 정확하게 찾도록 돕는지 확인합니다.

## 방식
- 비대면
- Discord 또는 Google Meet
- 카메라 불필요, 화면 공유만 사용
- 1인 약 10분

## 진행
1. 안내 및 동의: 약 1분
2. AI Promise 과제: 최대 4분
3. 직접 검색 과제: 최대 4분
4. 짧은 평가: 약 1~2분

두 과제는 난이도는 비슷하지만 기업 또는 문항을 다르게 합니다. 순서 효과를 줄이기 위해 참가자별로 서비스/직접검색 순서를 번갈아 배정합니다.

## 기록
- participant_id
- 수행 순서
- 각 과제 소요시간
- 정답 여부
- 이해도 1~5
- 신뢰도 1~5
- 면접 활용 의향 1~5
- 개선 의견

## 비실시간 참여
화면 공유가 어려운 사람은 링크와 설문으로 의견만 받을 수 있습니다. 이 응답은 UI 개선에는 사용하지만 시간·정답률 비교에는 포함하지 않습니다.

## 개인정보
공유 저장소에는 이름, 전화번호, 이메일을 저장하지 않습니다. 참가자는 `P01`, `P02`처럼 익명 ID로 기록합니다.

템플릿과 분석 스크립트는 `eval/user_test/`에 있습니다.
