# 사용자 테스트

Google Drive의 사용자 테스트 자료/기록지와 같은 구조로 관리합니다.

## 준비
1. `template.csv`를 복사해 `results.csv`로 사용합니다.
2. 참가자 이름·연락처는 적지 않습니다.
3. `R0`은 예행연습이고 정량 분석에서 제외합니다.
4. 본 테스트는 10명 목표, 최소 6명입니다.
5. 실시간이 어려운 참가자는 `의견 참여`로 기록하고 정량 분석에서는 제외합니다.

## 설문 (구글 설문지)

`create_form.gs`는 Drive의 `1015_AI_Promise_사용자테스트_설문지_최종`과 같은 문항·설정으로 구글 설문지와 응답 시트를 만듭니다. 순서는 기록지의 설문1~설문6 칸과 같습니다.

1. script.google.com > 새 프로젝트 > 이 파일 내용을 붙여 넣고 저장
2. `createSurvey` 실행 > 권한 허용
3. 실행 로그의 참가자용 응답 링크를 진행자에게 전달 (편집 링크와 응답 시트는 팀 안에서만)

이메일 수집과 로그인 요구는 끕니다. 같은 이름의 설문이 공통 폴더에 있으면 다시 만들지 않고 멈춥니다.

## 분석

```bash
python eval/user_test/analyze.py eval/user_test/results.csv
```

주 지표는 **4분 안에 정답을 찾은 비율**입니다.

시간은 4분 안에 완료한 사례만 평균/중앙값을 계산합니다. 시간 초과가 존재하므로 제한시간 값을 임의로 실제 완료시간처럼 취급하거나 "몇 분 단축" 수치를 만들지 않습니다.

전체 절차는 `docs/user-test-protocol.md`를 따릅니다.
