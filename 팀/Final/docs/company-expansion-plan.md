# 시연용 기업 확장 계획 (관문 2 통과 시)

기획 보고서(10월 12일 3차 개정)와 같은 기준입니다.

## 기업 수
- **기본 2곳**: 삼성전자(개발·시연용), SK하이닉스(평가용)
- **추가는 조건부**: 관문 2를 통과했을 때만 업종이 다른 시연용 기업을 **최대 3곳** 더할 수 있습니다.
- 시연용 기업은 사람 정답과 비교하지 않습니다. 화면에 시연용 안내(`check_note`)를 붙이고, 평가 숫자에는 넣지 않습니다.
- 문장 분류 ML 실험은 이번 제출(10/18)에서 하지 않습니다 (기획 보고서 8.3). 자세한 내용은 `eval/ml/README.md`에 있습니다.

### 기본 2곳의 역할
- 삼성전자: 개발용 (판정기준과 엔진을 맞추는 기업, 화면 시연)
- SK하이닉스: 평가용 (사람 두 명이 따로 매긴 정답과 AI 판정을 블라인드로 비교)

### 추가 후보
- 현대자동차
- NAVER
- LG전자 (삼성전자 DX와 같은 전자 업종이라, 업종이 다른 후보를 먼저 봅니다)

후보는 브랜드 인지도만으로 정하지 않고, 실제 공시에 판정할 약속이 있는지 먼저 확인합니다.

## 추가 GO 조건
2024 사업보고서의 지정 섹션에서 판정기준 v2에 맞는 **구체적 AI 약속이 최소 3개** 있어야 합니다. 2025 사업보고서나 2026 반기보고서에서 일부 약속이라도 근거 후보가 이어져야 합니다.

확인 명령 (engine 폴더에서, 후보 PDF 1개만 있으면 됨):

```bash
python run.py scan --company hyundai
```

마지막 줄이 "통과"여도 약속 목록을 판정기준 v2로 직접 읽어 봅니다.

## 추가 기업의 검증 수준
추가 기업은 다음을 모두 통과해야 합니다.
- 실제 DART 정기공시만 사용
- 약속 원문 보존
- 근거 원문 보존
- 인용 검사(Citation Verification) 통과
- `engine/run.py check` 통과
- 팀이 약속과 근거를 원문과 대조해 확인

다만 삼성전자·SK하이닉스처럼 두 사람이 모든 약속을 따로 판정하지는 않습니다.
