# 시연용 기업 계획 (10/19 확정, 22시 자동 선별 결과 반영)

10/12 기획 보고서 3차 개정에서는 "관문 2를 통과하면 업종이 다른 시연용 기업을 최대 3곳"으로 정했고, 10/19에 마감 최소안(`docs/final-sprint.md`)으로 3곳(카카오, 신한은행, NAVER)을 정했습니다. 10/19 저녁 OpenDART 자동 수집(PR #35)으로 후보를 실제로 돌려 본 뒤, 아래 기준으로 화면에 넣을 기업을 다시 골랐습니다.

## 화면에 넣는 조건 (처음부터 정해 둔 기준, 바꾸지 않음)
2024 사업보고서의 지정 섹션에서 판정기준 v2에 맞는 **구체적 AI 약속이 최소 3개** 있어야 합니다. 3개보다 적은 기업은 화면에 넣지 않습니다 (`engine/README.md` 6장, `python run.py scan`의 기본 기준 3개).

## 다시 돌리는 방법
GitHub Actions > `Engine run` > Run workflow (기업 목록 예: `["kakao","hyundai"]`). 결과는 `engine-results/<실행번호>-<기업>-<순번>` 브랜치에 올라가고, 확인 뒤 `python run.py export` → `python merge_screen.py ... --write` → Pull Request로 화면에 넣습니다. 자세한 명령은 `engine/README.md` 1장 "OpenDART 자동 수집"에 있습니다.
