# AI Promise: Executive Summary

## 한 줄
기업이 과거 공시에서 밝힌 AI 계획과 이후 실행 근거를 연결해, 취업·이직 준비자가 5분 안에 기업의 AI 전략을 원문 근거와 함께 확인하도록 돕는 서비스.

## 문제
- 기업 조사에는 여러 연도의 수백 쪽 공시를 읽고 비교해야 함
- 일반 검색/요약은 과거 계획과 후속 실행 근거를 연결하기 어려움
- 사용자는 AI의 결론보다 확인 가능한 원문 근거가 필요함

## 해결
1. AI 약속 추출
2. 후속 공시 RAG 검색
3. 4개 판정
4. citation verification
5. DART 원문 연결
6. 면접 카드

## 기술
- 생성형 AI
- RAG
- 자동화 워크플로우
- Agent-style retry
- Citation verification
- GitHub CI / UI QA

## 차별점
- 공시 요약이 아니라 '약속 ↔ 실행 근거' 비교
- 판정에서 원문으로 되돌아갈 수 있음
- '공시에서 확인 불가'를 미이행으로 단정하지 않음
- 면접 준비라는 실제 사용 맥락까지 연결
