# 정답 파일 폴더

- `<기업>_정답매길목록.csv`: 엔진(extract)이 만드는 빈 목록. AI 판정은 들어 있지 않습니다.
- `<기업>_김성태.csv`, `<기업>_서원.csv`: 위 목록을 복사해 각자 따로 판정한 파일
- `<기업>_합의.csv`: 판정이 다른 건을 원문을 보며 정한 최종 정답
- `<기업>_사람약속목록.csv`: 사람이 직접 찾은 약속 문장 ("약속 문장" 칸)
  - 삼성전자: 공유 폴더의 `1010_김성태_삼성전자_연습5건` 시트를 CSV로 받아 `samsung_사람약속목록.csv`로 저장
  - SK하이닉스: 서원님의 `1010_서원_SK하이닉스_약속목록`을 CSV로 받아 `skhynix_사람약속목록.csv`로 저장
  - 맨 위 안내 줄, "예" 줄, "약속 문장 (원문 그대로)" 같은 칸 이름은 고치지 않아도 평가 코드가 알아서 읽습니다.

판정 칸에는 `근거 확인`, `일부 확인`, `공시에서 확인 불가`, `회사가 미추진으로 공시` 중 하나를 그대로 씁니다.
참여자 이름이나 연락처가 든 파일은 이 폴더에 두지 않습니다.
