# AI Promise Final Project 결과보고서 초안

> 실제 결과가 아직 없는 칸은 [입력]으로 남겨 두었습니다. 제출 전 사실로 확인된 값만 넣습니다.

## 1. 프로젝트 개요
AI Promise는 기업이 정기공시에서 밝힌 AI 계획과 이후 정기공시의 실행 근거를 연결해 보여주는 AI 기반 기업 조사 서비스입니다. 주 사용자는 취업·이직 준비자이며, 단순 요약이 아니라 '과거 약속 → 후속 근거 → 판정 → 원문 → 면접 활용' 흐름을 제공합니다.

## 2. 문제
기업의 AI 전략을 확인하려면 긴 사업보고서를 여러 연도에 걸쳐 직접 비교해야 합니다. 일반 검색이나 요약은 과거 계획과 후속 실행 근거를 체계적으로 연결하지 못하는 경우가 많습니다.

## 3. 해결 방법
- 2024 사업보고서에서 AI 관련 미래 계획 추출
- 구체적 약속과 방향성 문장 분리
- 2025 사업보고서/2026 반기보고서에서 근거 검색
- 4개 상태로 판정
- 근거 원문 exact-match 검증
- 검증된 결과를 면접 카드로 변환

## 4. AI Native 기술
### RAG
후속 공시에서 관련 근거 문단을 검색해 LLM 판정에 제공합니다.

### 자동화 워크플로우
OpenDART 자동 수집(또는 DART PDF) → Collect → Extract → Retrieve → Judge → Verify → Card → results.json → Web UI

### Agent-style retry
AI 판정이 '공시에서 확인 불가'이면 새 검색어로 다시 찾습니다(처음 검색 포함 최대 3번, 쓸 새 검색어가 없으면 그 전에 멈춤).

## 6. 데이터와 검증
- 검증 시연 기업 (사람이 공시 원문 대조): 삼성전자(개발용), SK하이닉스(평가용)
- 확장 분석 기업 (AI 엔진 결과, 사람 검토 전): 카카오, 현대자동차, 신한지주

확장 분석 기업은 10/19 OpenDART 자동 수집으로 후보 11곳을 돌려, 미리 정한 기준(2024 사업보고서의 구체적 AI 약속 3개 이상)을 넘은 기업만 넣었습니다. 기준 미달 기업(신한은행, NAVER 등)과 이유는 `docs/company-expansion-plan.md`에 있습니다.

SK하이닉스는 김성태·김서원이 AI 결과를 보기 전에 공동 검토로 정답을 고정했고, 최종 엔진을 3번 돌린 시범 평가(n=3)에서 9번 중 7번 같았습니다(`eval/results/skhynix_runs.md`). 건수가 적어 정확도로 주장하지 않습니다. 확장 분석 기업은 사람 정답과 비교하지 않았고 평가 수치에 넣지 않습니다.

검증 시연 기업 2곳의 화면 데이터는 실제 공시를 사람이 원문과 대조한 검증용 시연 데이터입니다(PR #19). 확장 분석 기업 3곳은 AI 엔진 결과이며, 화면에 "AI 엔진 · 사람 검토 전" 배지를 붙여 구분합니다. 설문 점수는 화면 구성과 근거 제시 방식에 대한 평가로 해석하고 AI 판정 정확도로 쓰지 않습니다.

## 12. 한계와 후속연구
- 공시에 나오지 않은 실행은 판단할 수 없음
- 기업별 공시 문체 차이로 retrieval 성능 편차 가능
- 확장 분석 기업 3곳은 사람 검토 전 AI 엔진 결과라, 사람이 원문을 대조한 검증 시연 기업보다 검증 깊이가 낮음
- 후속연구에서 기업 수 확대, 문장 분류 benchmark, cross-company validation 가능

## 13. 결론
AI Promise는 기업을 대신 평가하는 서비스가 아니라, 사람이 공식 공시를 더 빠르고 검증 가능하게 읽도록 돕는 AI 조사 도구입니다.
