# Final Sprint: 최소 완성안

## 목표
공식 Final Project 필수요건을 우선 충족한다.

## 기업
- Core 2: 삼성전자, SK하이닉스
- Demo 3: 카카오, 신한은행, NAVER

## 절대 우선순위
1. 실제 서비스 URL
2. 실제 사용자 5명 이상
3. 피드백 수집
4. 피드백 1~2건 실제 반영
5. GitHub README에 결과·역할·링크 정리
6. 발표자료
7. 여유가 있으면 Demo 3 추가

## 사용자 테스트 최소안
- 대상: 실제 사용자 5명 이상
- 시간: 1인 약 5분
- 진행: 서비스 링크 전달 → 기업 1개를 2~3분 사용 → Google Form 제출
- 필수 설문: 이해도, 신뢰도, 활용 의향, 개선 의견
- 비교검색 A/B는 이번 최소 제출안에서는 필수가 아니다.
- 참가자 ID만 사용하고 개인정보는 저장하지 않는다.

## 피드백 반영 증빙
최소 1건, 가능하면 2건:
- 사용자 의견
- 문제
- 수정 내용
- GitHub commit/PR
- 수정 후 화면 캡처

## 발표에서 강조
- DART 기반 공식 데이터
- RAG + Agent-style workflow
- citation exact-match verification
- AI가 '미이행'을 단정하지 않는 윤리 설계
- 실제 사용자 5명+ 피드백 반영
